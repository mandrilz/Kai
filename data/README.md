# Данные

Поместите сюда XLSX файлы с данными:

- `K.ai_database_kometta.xlsx` - база данных насосов Кометта
- `K.ai_database_competitors_cnp.xlsx` - база данных конкурентов (CNP и др.)

## Формат файлов

Файлы должны содержать следующие колонки:

### Обязательные колонки:
- `brand` - бренд
- `series` - серия
- `model` - модель
- `articul` - артикул
- `power` - мощность (кВт)

### Колонки с кривыми:
- `graphic_q_1` ... `graphic_q_14` - расход Q (м³/ч)
- `graphic_h_1` ... `graphic_h_14` - напор H (м)

Примечание: десятичные запятые будут автоматически преобразованы в точки.

## Настройка пути

Путь к этой папке настраивается через переменную окружения `DATA_DIR` в файле `backend/.env`.

Для локальной разработки:
```
DATA_DIR=../data
```

Для production:
```
DATA_DIR=/var/www/kai/data
```
